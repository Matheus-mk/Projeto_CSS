# 📰 TechNews Today

 Projeto desenvolvido como parte do desafio de criação de um portal de notícias moderno e responsivo, utilizando apenas **HTML e CSS**.

 ## 📌 Sobre o projeto

 O **TechNews Today** é uma página de notícias com um visual moderno, utilizando efeitos de **Glassmorphism**, textos com gradiente e um layout organizado com **CSS Grid**.

 O projeto foi desenvolvido seguindo os requisitos propostos no desafio, sem a utilização de frameworks ou JavaScript.

 ## ✨ Funcionalidades e recursos

 - 🪟 Header com efeito **Glassmorphism**
- 📌 Header com `position: sticky`
- 🌈 Título com efeito de **gradiente no texto**
- 📐 Layout desenvolvido com **CSS Grid**
- 🎥 Área para vídeo
- 📩 Seção de newsletter
- 📱 Design responsivo para dispositivos móveis
- 💻 Media query para adaptação em telas menores
- 🎨 Estilização feita exclusivamente com CSS
- 🚫 Sem frameworks
- 🚫 Sem JavaScript

 ## 🎯 Requisitos do desafio

 O projeto atende aos seguintes requisitos:

 - [x] Glassmorphism com `backdrop-filter`
- [x] Gradiente no texto
- [x] CSS Grid no layout
- [x] Header com `position: sticky`
- [x] Media query para dispositivos móveis
- [x] No máximo 50 linhas de CSS
- [x] Sem frameworks
- [x] Sem JavaScript
- [x] HTML original preservado

 ## 📱 Responsividade

 A página foi desenvolvida para se adaptar a diferentes tamanhos de tela. Em dispositivos menores, o layout é reorganizado por meio de **Media Queries**, proporcionando uma melhor experiência de navegação em smartphones e tablets.

 ## 🚀 Como executar

 1. Clone este repositório ou faça o download dos arquivos.
2. Mantenha `desafio10a.html` e `10a_desafio.css` na mesma pasta.
3. Abra o arquivo `desafio10a.html` em um navegador.
4. Confira o resultado do portal.

 > ⚠️ É importante manter o nome `10a_desafio.css` exatamente igual ao utilizado no link do arquivo HTML para que os estilos sejam carregados corretamente.
